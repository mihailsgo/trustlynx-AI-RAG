# Screen: The same signature box with a handwritten signature drawn in it

![The same signature box with a handwritten signature drawn in it.](knowledge/raw/padsign/images/screen-signature-pad-signed.png)


The signature area with a signature drawn in it — the state immediately before tapping
**Sign**.

The stroke appears in blue ink inside the dotted-bordered box. It is a single continuous curve
here, but the box accepts several separate strokes equally well, so a signature with gaps in it
or separate initials works normally.

The two buttons below are unchanged: **Clear** on the left to empty the box and start again,
**Sign** on the right to submit.

The mark shown here is a synthetic stroke drawn for documentation purposes, not anybody's real
signature.

Once **Sign** is tapped, this whole area is replaced by a progress panel and the **Sign** button
stops responding — deliberately, so the document cannot be submitted twice.
