# Screen: The resting screen, showing only a centred logo and a footer

![The resting screen, showing only a centred logo and a footer.](../images/screen-idle-waiting.png)


The pad's resting screen, which is what it shows between visitors. A single logo sits
centred in the upper part of an otherwise empty page, with a copyright line along the
bottom.

This is a working state, not a fault and not a loading screen. There is no document on the
pad, so nothing else is drawn — no document area and no signature box.

In the top-right corner of this particular capture there is a **Load DEMO PDF** button and a
small box showing the account and organisation the device is signed in as. Those only appear
on devices set up for evaluation. A pad in normal use shows the logo alone.

Nothing here needs tapping. The pad checks for a waiting document by itself every few
seconds, and a document appears on its own when one is sent.

## Questions this answers

- What does the waiting screen look like?
- Why does the tablet only show a logo?
- What should the pad show when nothing is happening?
