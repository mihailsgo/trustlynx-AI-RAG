# Screen: The progress panel with all four steps complete and a message that the document was signed successfully

![The progress panel with all four steps complete and a message that the document was signed successfully.](knowledge/raw/padsign/images/screen-progress-success.png)


The confirmation panel, shown once signing has completed successfully.

The heading reads **The document has been successfully signed. The page will automatically
reload in 5 seconds.** Below it, in smaller grey text, *Page will refresh in 5...* — a countdown
that ticks down each second.

The progress bar is fully filled in green with **100%** in the pill to its right. All four steps
below it — Preparing document for signing, Applying visual signature, Applying digital stamp,
Finalizing workflow — show green circles with ticks and green labels.

The countdown is not a deadline for the person signing, and this is the point most worth
understanding about this screen. By the time it appears, the document has already been signed,
stored, and handed onward to wherever the organisation's setup sends it. The reload only clears
the display so the pad is ready for the next visitor. Nothing is lost when it happens and there
is nothing to do before it does.
