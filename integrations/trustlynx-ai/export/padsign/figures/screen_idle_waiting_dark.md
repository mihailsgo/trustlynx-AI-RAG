# Screen: The resting screen in dark mode, showing the logo on a dark background

![The resting screen in dark mode, showing the logo on a dark background.](../images/screen-idle-waiting-dark.png)


The same resting screen as in normal light mode, but on a device whose system appearance is
set to dark. The background is dark and the text and panel edges are lightened to suit it.

No configuration produces this. The interface follows the device's own light-or-dark setting
automatically, so a tablet switched to dark mode shows a dark PadSign without anyone
changing a PadSign setting.

The logo is unchanged, and the layout is identical to the light version — the same centred
logo, the same footer, and in this evaluation capture the same **Load DEMO PDF** button and
account box in the top-right corner.

## Questions this answers

- What does the pad look like in dark mode?
- Why is the screen dark with just a logo?
