# The signature area on screen, element by element

The signature area appears along the bottom of the screen once a document is open.
It is fixed in place, so it stays visible while you scroll the document above it.

![The empty signature box with Clear and Sign buttons underneath](knowledge/raw/padsign/images/screen-signature-pad.png)

## The elements

**The signature box.** A wide rectangle with a thin dotted border. This is where you
draw, with a finger or a stylus. The ink appears in blue. It is empty until you draw
in it.

**Clear** — the left button. Empties the signature box completely so you can draw
again. It only affects the signature; anything you typed into the document is left
alone.

**Sign** — the right button. Submits the document. Nothing is sent until this is
tapped. After tapping it, the button stops responding on purpose so the document
cannot be submitted twice, and a progress panel takes over the screen.

**Signer: <name>** — an optional line above the box, naming the person the document
was prepared for. It appears only in setups that have this switched on.

![The signature box with a Signer name label above it](knowledge/raw/padsign/images/screen-signer-name-label.png)

## When the area is not there

If you see a document but no signature box, the document is still loading. If you
see neither, no document has been sent to the pad yet and the screen will be showing
just a logo.

The area also disappears once you tap Sign — the progress panel replaces it — and it
does not come back, because that document is finished.
