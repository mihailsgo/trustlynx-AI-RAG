The signing confirmation panel on a device set to dark mode.

The content is identical to the light version — the heading confirming the document was signed
successfully, the countdown line beneath it, a fully filled progress bar showing **100%**, and
all four steps marked with ticks.

What changes is only the treatment: the panel sits on a dark surface with light text, and the
green used for the completed steps and the progress bar is adjusted so it stays legible against
the darker background rather than glaring.

This is the same automatic behaviour as the rest of the interface. The panels follow the device's
own light-or-dark appearance setting, with no PadSign configuration involved.
