The signing screen with a document open, on a device set to dark mode. The interface around
the document — header, background, and the signature band along the bottom — follows the dark
scheme.

The document itself stays on a light background. That is deliberate rather than an oversight:
inverting the colours of a contract or consent form would change how it reads and could
misrepresent it, so the page is rendered as the PDF defines it regardless of the device's
appearance setting.

The result is a dark frame around a normally-rendered document. Everything else works
identically to light mode — the same signature box, the same **Clear** and **Sign** buttons in
the same places.
